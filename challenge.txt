LAB 02 CHALLENGE ADD-ONS - PHP Output and Bootstrap 5.3 Redesign

Complete the 8 challenge add-ons below after finishing the tutorial activity.

1. Student Variables
   Create variables for your full name, course, year level, and section.

2. Echo Output
   Display all student variables using echo.

3. Print Output
   Display the same student variables using print.

4. Label Each Value
   Add clear labels before each value, such as Name:, Course:, Year Level:, and Section:.

5. Line Break Formatting
   Use <br/> tags so each label and value appears on a separate line.

6. Sentence Output
   Create one complete sentence using variables, then display it with echo.

7. Bootstrap 5.3 Alternative Redesign
   Redesign the PHP output page using Bootstrap 5.3 instead of Tailwind CSS. Use Bootstrap cards, badges, alerts, and tables to present PHP variables and output clearly.

8. Output Comparison
   Add a PHP comment explaining one difference you observed between echo and print.

Submission:
Submit the edited index.php file and a screenshot of the browser output.
