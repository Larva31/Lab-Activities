LAB 01 CHALLENGE ADD-ONS - XAMPP Setup and Tailwind CSS Redesign

Complete the 8 challenge add-ons below after finishing the tutorial activity.

1. Custom Welcome Message
   Change the page output to display your full name and section.

2. Localhost Proof
   Add a second line that displays: This page is running from localhost.

3. Course Identification
   Add another line that displays the course code and subject title.

4. Date Display
   Use PHP to display the current date using the date() function.

5. Multiple Echo Statements
   Use at least three separate echo statements in index.php.

6. Browser Line Breaks
   Use <br/> tags so each message appears on a separate line in the browser.

7. Tailwind CSS Redesign
   Redesign the PHP output page using Tailwind CSS utility classes. Add a styled page container, readable text, spacing, background color, and at least one styled heading.

8. Screenshot Evidence
   Submit a screenshot showing the browser URL and the redesigned final output.

Submission:
Submit the edited index.php file and a screenshot of the browser output.
